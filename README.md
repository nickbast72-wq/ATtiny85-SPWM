# ATtiny85-SPWM
SPWM generator for power inverters (50-60Hz) with two complimentary, phase-correct SPWM outputs, frequency setings, voltage feedback and FAULT input.The generation of SPWM is accomplished in a non-traditional way - through simple integer mathematics, without heavy sine functions or volumetric tables. It is based on the equation (((a-x^2)/b)^2)/c, whose graph contains a fragment in the shape of a sinusoidal half-period. The sine wave is calculated in real time. The resolution is 158 steps for the entire period (20ms). The SPWM frequency is around 8kHz - oriented for IGBT bridges. The processor runs on 16MHz PLL.Phase-correct PWM creates a doubling of the output frequency (at full bridge), while transistors operate at a low frequency with low losses. This makes it easier to filter the output voltage with a smaller inductor. The frequency and amplitude of the sinusoidal voltage are adjusted at the top of each half-period, i.e. every 10ms at 50Hz). The FAULT input triggers an interrupt at logical 0, From which it follows immediately logic 0 at both PWM outputs.This state lasts about 1 second. If after this time the FAULT input is not active, the SPWM generation is resumed. If the FAULT continues to be active after this time, the processor stays the outputs at 0 and enters an infinite loop, that is, a restart is required for normal operation.Starting the SPWM signal (also after FAULT) always starts from the sinusoidal zero.
